Reproduction and evaluation details

Reproduction required API/model substitutions and fixes to the local Hunyuan3D adapter. The run uses 3,000 physics steps. Source-mask registration uses supplied calibration for synthetic scenes and estimated intrinsics for real images.

The source row scores TabletopGen’s saved pyrender output against SceneRig’s existing Cycles rerenders. The calibrated-source and novel rows use Cycles for both methods; renderer versions, sample counts, lights and backgrounds are not normalized. The qualitative panels above use the archived Cycles views used for VLM evaluation, so they differ from the TabletopGen saved source images scored in the first row. Images are resized and WebP-encoded for display, with no brightness adjustment; metrics use the original images.

Both methods use the same +30° azimuth rule around their registered scenes, preserving each method’s orbital radius and elevation. This does not imply identical camera extrinsics. Object-layout scores use global scale alignment; OSPA values and cutoffs are in centimeters. Real scenes lack object and novel-view ground truth.

The 21 incomplete runs comprise 17 top-view quality-check failures, three Seedream input rejections and one missing support surface. These completion counts describe this reproduction with its substitutions, not the original authors’ reported success rate.
